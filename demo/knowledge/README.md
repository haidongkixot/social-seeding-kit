# knowledge/: the only source of facts

Every factual claim in a message must come from a file here. The reviewer drops any item with a claim it cannot trace to one of them.

How to approve: change `status: DRAFT` to `status: APPROVED (Name, YYYY-MM-DD)` at the top of each file. Agents use only APPROVED files when drafting live items. Draft-only days may use DRAFT files, and those items are clearly marked.

Lines marked `[CONFIRM]` are things not yet known. The writer must not use them until they are filled in.

Add one file per topic: `company.md`, `products/<category>.md`, `promotions/general.md`, `faq.md`. Keep each fact a short, approved statement.
